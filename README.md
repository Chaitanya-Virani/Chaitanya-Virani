### 🔥 Featured Projects

**Minutely** — *AI-Powered Meeting Intelligence*
Ingests meeting transcripts (CSV/PDF/DOCX/TXT/MD) and context documents, and returns a structured PDF with action items, decisions, risks, key dates, and per-participant summaries.
- Anthropic Claude API with tool use for schema-enforced structured output, backed by Pydantic validation
- Prompt caching to cut token cost and latency on repeated runs
- Stateless FastAPI backend with in-memory ReportLab PDF rendering and modular multi-format parsers
- Dockerized and deployed on Railway

`Python` `FastAPI` `Anthropic API` `Docker`

[![Repository](https://img.shields.io/badge/Repository-111827?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chaitanya-Virani/Minutely)

**Customer Insight Triage System (CITS)**
Detects and prioritizes high-urgency customer reviews instead of leaving them for manual triage.
- TF-IDF + supervised ML models, with a full pipeline from preprocessing through feature engineering and evaluation (Precision, Recall, F1)
- Dynamic, weighted keyword scoring that ranks complaint severity and adapts to evolving language

`Python` `scikit-learn` `NLP`

[![Live Demo](https://img.shields.io/badge/Live%20Demo-2563EB?style=for-the-badge&logo=render&logoColor=white)](https://cits-u9pn.onrender.com/)
[![Repository](https://img.shields.io/badge/Repository-111827?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Chaitanya-Virani/CITS)

**[CrossKey Crypto Wallet](https://github.com/Chaitanya-Virani/CrossKey-Crypto-Wallet)** — *6th place / 100+ teams, HackNUthon'25*
A React-based wallet manager for Ethereum and Polygon testnets — generate or import a wallet, check balances, and send transfers behind a password-protected UI.

`React` `JavaScript` `Web3`
